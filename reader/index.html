Questions

Does it need access to all my files?

No. Shadow Reader uses Android's own folder picker, so it can read the folders you hand it and nothing else. It never asks for all-files access.

Can it open DRM-protected books?

No, and it does not try. A file with Kindle or Adobe DRM is recognised and named as such, so you know why it will not open rather than being told the file is broken.

How does sync work without an account?

It writes to a folder only the app can see in your own Google Drive, or to a WebDAV server or local folder you choose. Your devices read each other's changes from there. There is no server of ours in the path, and nothing of yours to sign into.

Is read-aloud a paid feature?

No. Playback — background, screen off, media notification, sleep timer, speed and voice — is free for everybody. Pro adds the cast: a separate voice for the narrator, the dialogue and up to twelve named characters.

Is Pro a subscription?

No — a single payment through Google Play, bought once. There is no online licence check, so it keeps working offline, after a reinstall and on your next phone.

Is there an iPhone version?

Not today. Shadow Reader is Android only.
